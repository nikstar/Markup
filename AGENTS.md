# Standalone Markup

Use the Telegram iOS implementation as the reference for drawing, selection, tool UI, and motion. The user explicitly authorizes copying whole components and large sections of Telegram source and artwork into this independent AppKit project. Keep the applicable licenses, attribution and source mapping. Adapt UIKit input and presentation to AppKit and include all build dependencies within this directory.

Install Markup in `/Applications/Markup.app`. Test without taking focus. After each completed set of changes, quit the installed app normally, reinstall the verified build, and reopen it. The user may be testing in parallel.
