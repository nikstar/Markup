Choose **Check for Updates…** from the Markup menu or the menu-bar pencil to download and install new versions through Sparkle. Enable **Automatically check for updates** in Settings for periodic checks. When Markup is in the background, the pencil changes to a download arrow when an update is ready to review.

If you’re using Markup 1.0.x, download **Markup-1.1-macOS.zip** and replace your copy in **Applications** once to get the updater. Requires macOS 27 or later on Apple silicon.
